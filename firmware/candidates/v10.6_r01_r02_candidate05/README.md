# V10.6 R01/R02 candidate05 — 未下载

板上仍为 V10.5。本目录两种配置基于相同源码快照；manifest 记录构建标志、SDK、SHA-256 与未下载状态。SOP8 通用配置保留 SWD 引脚保护，不是完整 H 桥产品交付固件。

通用 ADC IIR 改为 Q16 内部精度，避免整数截断吞掉小变化。原版两种配置各 3/16 项失败；candidate04 的 Q8 在额外的最强滤波 +1 count 测试中仍失败，因此保留失败证据并升级到 Q16。candidate05 在模拟 HAL 中按开发板和 SOP8 配置各通过 19/19 项，含正反 1 count 和全量程变化。当前 LCDM 现场控制不调用该通用 IIR，LCDM BIN 与 candidate03、04 字节相同，不能解决 LCDM 的 1–2 µs HOLD 缺陷。

通用 PWM 默认 500/2500 µs 且保留 CRC 有效旧标定；输入捕获四种板型/覆盖组合各 46/46、参数模拟 Flash 9/9、通用映射 7/7。LCDM 源码 27 项检查包含对微步缺陷的复现，不代表 R01 通过。实际 PCB、输入源、角度、真实电压、微步、波形、失联恢复和稳定性仍待实测。
