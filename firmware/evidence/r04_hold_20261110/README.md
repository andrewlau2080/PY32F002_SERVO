# R04 HOLD 阶段发布频率的粗采样

V10.5 的 50 秒 SWD 记录中，430 个序号与误差一致的采样帧处于 HOLD/event 2。相邻采样帧之间的发布序号按每次发布加 2 换算，共 49904 个发布间隔、帧时间相差 49904 ms，平均约每秒 1000 次。

SWD 采样帧之间相隔 82–307 ms；只能获得较长时间平均值，不能证明期间每次执行的间隔、所有中间帧的状态、HOLD 不会漏算或 UI/SWD 对实时性的影响。片段无受控输入跳变，不能验证命令到 duty 延迟。原始数据及哈希见 `firmware/releases/v10.5/r01_validation_20261110/field03/trace.csv` 与本目录 `report.json`。
