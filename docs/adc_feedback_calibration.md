# ADC 反馈实测记录

版本：v0.1

用途：记录 PA3 电位器反馈 ADC 的实测范围，后续闭环反馈程序不要假设 ADC 最小值为 0、最大值为 4095。

## 1. 当前测试固件

编译开关：

```bash
BOARD_TSSOP20_DEBUG_PINS=1 SERVO_ENABLE_HBRIDGE_IO_TEST=1 SERVO_ENABLE_ADC_LED_TEST=1 SERVO_IO_TEST_ENABLE_GPIOB=1 HBRIDGE_PWM_TICK_US_OVERRIDE=100
```

测试方式：

| PA3 电压范围 | H 桥 LED 表现 | 当前临时映射 |
|---|---|---|
| 实测最低端到中点 | 一端 LED 从灭到亮 | ADC raw `213-2056` 映射为反向 duty `0-1000`；`<=225` 强制关断 |
| 中点到实测最高端 | 另一端 LED 从灭到亮 | ADC raw `2056-3900` 映射为正向 duty `0-1000`；`>=3900` 满 duty |

注意：这是临时 LED 可视化测试映射。实际舵机闭环要使用实测 `adc_min_count`、`adc_center_count`、`adc_max_count`。

## 2. 已确认现象

LED 不能完全变暗，说明当前 PA3 输入端、外部电位器/分压/滤波电路或 ADC 偏置下，实测最小 ADC raw 不一定等于 0。

后续程序处理原则：

| 参数 | 说明 |
|---|---|
| `adc_min_count` | 取 PA3 实测最低机械位置 raw，不使用固定 0 |
| `adc_center_count` | 取电位器中点或舵机机械中点 raw，不固定写死 2048 |
| `adc_max_count` | 取 PA3 实测最高机械位置 raw，不使用固定 4095 |
| 电压换算 | `Vadc_mv = raw * VDD_mv / 4095` |

## 5. 当前TSSOP20仿真板静态观察（非中心校准）

**PWM使用范围更新（2026-11-15）**：用户确认此前机械两端参数按500–2500µs假设，正常使用收窄为600–2400µs，预留两端机构余量。固件P20标定默认InL/InH为600/2400µs；这不是重新测得的机械端点，也不要求转到机械极限。1500µs中立独立保留，Lo/Md/Hi及两侧映射分别校准，不要求对称。

|---|---:|---:|---:|---:|---|---|
| 2026-11-14 P160H force-coast | 1503µs | 1941–1947 / 1943 | 3262–3273mV / 3269mV | 折算范围1548.5–1556.2mV，中位数约1551.2mV | 目标2052；反馈1941–1948 | 8秒只读43帧，配对年龄0–19ms；机械中位未确认，折算值来自VREFINT而非独立万用表 |

- 这条记录显示当前反馈比1503µs的名义目标低约104–111 ADC（约84–90mV，按VDD估算），但由于机械中位未确认，不能直接把它判作电气零偏或把`Md`改为1551mV。
- H版PA0电位器供电开关开启；源码将PA0推挽拉高作为临时电位器供电脚。若现板接线确实如此且电位器与ADC共地，电位器读数应大体与MCU供电成比例；直接按VDD乘raw可能制造位置偏移。当前静态trace Pearson相关约+0.0015，故尚无依据添加补偿系数。
- 当前只验证TSSOP20。下一步先确认机械中位，再依据同一时段raw/VDD计算中心校准；随后在低占空、微小步进条件下同步观察位置与VDD负载变化。R02/R22仍未通过实体电压、端点和动态反馈验收。

结论：

- 当前已实测到 PA3 最低端当前 raw 为 `213`，约 `174mV`；同次运行自动捕捉最低 raw 为 `189`，约 `154mV`，所以后续反馈程序不能把 ADC 最低点当作 `0`。
- 当前已实测到 PA3 最高端当前 raw 为 `3900`，约 `3175mV`；同次运行自动捕捉最高 raw 为 `3929`，约 `3195mV`，所以后续反馈程序不能把 ADC 最高点简单当作 `4095`。
- 后续闭环建议先按实测机械行程写入 `adc_min_count / adc_center_count / adc_max_count`。LED 测试映射也应改为“实测 min 到 center、center 到 max”映射，而不是固定 `0/2048/4095`。

## 4. 接口、PWM 与位置校准合并记录

名义 ADC 电气量程为 MCU 输入 `0–3.3 V` 对应 12 bit raw `0–4095`；电压换算应使用同时测得的 VDD：`PA3_mV = raw × VDD_mV / 4095`。这只是 MCU 电气量程，舵机实际机械端点不应假定覆盖 0/4095。

舵机规格书 CYS-S3047 第 6 节给出 PWM `500–2500 µs`、中立 `1500 µs`、`1000–2000 µs` 标称 90°操作行程、`500–2500 µs` 约 180°最大行程；规格书没有给 PA3 电位器的输出电压。下表把规范、固件目标和实体测量放在同一条记录中；“待实测”项不能用默认映射替代：
