# R12 分项性能指标核对

最后更新：2026-11-19
对象：TSSOP20 LCDM；规格参考、历史实测与当前验收证据分开记录。
结论：**R12尚未整项通过。资料明确给出回中误差≤0.5°、1000–2000µs行程角误差≤2°及CYS-S3047空载速度参考；当前固件同版测量未证明达标，过冲、抖动和稳定时间门槛仍缺。**

## 项目已有的规格参数

来自项目内《舵机规格书.pdf》（CYS-S3047，2020-04-25）及需求文档：

| 参数 | 规格值 | 使用边界 |
|---|---:|---|
| 项目统一工作电压 | 4.8–8.4 V | 按用户确认合并CYS-S3047与S0100范围；不等同MCU VDDA/VDD |
| 空载速度 | 5 V：0.133 s/60°；6 V：0.115 s/60° | 空载规格，不承诺带载速度 |
| 中立脉宽 | 1500 µs | 用户另确认可按机构调中心偏移 |
| 标称行程 | 1000–2000 µs约90° | 规格行程参考 |
| 全脉宽范围 | 500–2500 µs约180° | 机械极限参考；用户已确认日常只用600–2400 µs，不需碰端点 |
| 输入死区 | 规格书6–12 µs | 与项目1–3 µs小指令检查分开；死区和小步运动不能混为同一指标 |
| 中立回归误差 | ≤0.5° | S0100参数要求；1500µs经往返后回归原位 |
| 标称行程角误差 | ≤2° | S0100参数要求；1000–2000µs约90–100°行程 |
| 运动连续性 | 不可跳动 | S0100研发要求；须同版实体动作核验 |
| 工作温度 | −10至+50°C | 规格环境范围 |

另有项目历史调试记录（`docs/lcdm_screen_layout_plan.md`），数值只代表对应版本和当时机构/供电：

| 历史数据 | 记录值 | 用途限制 |
|---|---:|---|
| 2026-06-19，V7.6d内部16秒测试 | 最大过冲26 ADC；最大终误差26 ADC；平均终误差9.8 ADC；duty范围−389…+480；event18=0、event16=0 | 历史单版测试，不是当前候选统计或产品限值 |
| 2026-06-19后续调试，1000µs方向 | 7段过冲均0 ADC，HOLD平均约380 ms | 对应当时版本与测试条件 |
| 同批1500µs方向 | 最大过冲1 ADC，HOLD约422 ms | 同上 |
| 同批2000µs方向 | 最大过冲2 ADC，HOLD约476 ms | 同上 |
| 更早V7.6d优化前试验 | 1000方向平均过冲10.4 ADC、最大52；2000方向约0–5 ADC；终误差曾在±12 ADC内 | 另一历史阶段，不能与后续数据拼成同版统计 |

上述ADC计数不能直接换算成角度，除非使用该版对应的有效校准映射。S0100参数表已给出回中误差≤0.5°、1000–2000µs标称角度相对误差≤2°；需在当前PA4校准映射下转成角度并实测。资料未规定当前固件在具体负载下的最大过冲、静止峰峰抖动或稳定时间。

## 当前代码/测试参数与状态

- 目前可采集位置误差、overshoot、state、event等字段；不同版本历史CSV及host simulation不是同版、同工况数据，不能合并统计。
- R11源码当前有静态偏移确认8 ms、负载确认30 ms；通用HOLD默认连续稳定20 ms、速度门槛36 Q4/ms。这些是实现参数，不代表R12产品验收限值，也不能替代LCDM实机静稳数据。
- CYS-S3047测速参考按5V、6V分栏，并记录实际舵机供电、负载、行程和温度；不能把空载规格当成带载承诺，也不能直接外推到项目4.8–8.4V全范围。
- 规格核对与历史数据整理不需要连接仿真器。要判断当前固件表现，则需在同一TSSOP20候选和固定条件下多次运动并保留原始CSV；内部PWM可触发，无需外部PWM发生器。

## 未通过原因与后续验证

1. 尚未在同一候选、固定供电/负载/行程下重复测出运动时间、峰值过冲、停点误差、稳定时间和静止峰峰波动。
2. 历史参数/结果对应不同固件与工况，只能作参考，不能宣称当前版本达标。
3. 原始需求已规定中立回归≤0.5°、标称行程角误差≤2°，但当前版本尚无有效角度校准及同版测量证明。最大过冲、静止峰峰抖动和最长稳定时间仍无数值门槛。现阶段按统一口径采数并将已有规格限值与未定指标分开报告；不得把历史参考擅自改写成用户确认的产品门槛。
4. 实测需当前候选、DAPLink、舵机/电位器和可观察转臂；按600–2400 µs日常范围测试，机械端点留在最后且无需为R12触碰。需记录供电、方向、命令跨度、运动时间、最大过冲、到位误差、进入HOLD时间及稳定段ADC峰峰值。

本次复核更正：项目供电范围按用户最新决定统一为4.8–8.4V；补记S0100回中≤0.5°、标称角误差≤2°和不跳动要求。规格与验收缺口已同步到开发规格及需求矩阵。未操作仿真板，未改固件，未运行构建或测试。
