# R12 分项性能指标核对

日期：2026-11-11  
对象：需求矩阵与现存 V10.x 证据  
结论：**R12 未通过；当前没有按四类症状逐项定义门槛并完成同版多轮统计。**

## 已核对内容

- 工程可记录位置误差、overshoot、state、event 等字段；现存 V10.2 实测、V10.5 静止采样及 host simulation 各自有不同范围和版本，不能拼成同一固件、同一工况的验收统计。
- 舵机规格书性能参考：5 V 空载 60°行程约 0.133 s，6 V 空载约 0.115 s。它可作为速度参考，但需要匹配实测供电、负载、角度定义和多次统计。
- 矩阵尚未给“过冲/不到位/静止抖动”规定数值门槛，也没有同一版固件对正反向、行程和工况重复测试的分布统计。

## 未通过原因与所需协助

- 不能仅凭某条改善波形或模拟结果宣布速度、过冲、停点误差、静稳全部合格。
- 现阶段需要先修复/核实 R03 时间基准、R08 轨迹和 R11 HOLD；否则运动时间、峰值过冲和静稳指标可能基于不一致的时钟/控制路径。
- **需要用户协助**：提供或确认产品可接受的最大过冲角度、到位误差/死区、静止峰峰抖动、最长稳定时间；若无现成限值，可在后续试验前共同从规格、机械限制和现场要求确定。速度参考按 5V/6V 规格分开记录，不外推为带载承诺。
- 实测还需 DAPLink 可用、舵机/电位器连接且可观察转臂；内部 PWM 可触发，不需要外部输入信号源。每方向/行程/供电做重复动作并保留原始 CSV。

R01–R11 未通过项留待后续统一复核，本轮未重跑。
