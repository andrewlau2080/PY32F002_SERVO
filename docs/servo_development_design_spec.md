# 舵机控制器开发设计规格书

**文件性质：** 内部研发基准，不是客户交付规格书。客户规格书将来从本文件中筛选已定型、可承诺且已有验收证据的内容。

**当前适用范围：** 以TSSOP20仿真/调试板落实和验证功能；SOP8暂缓。此规格覆盖系统目标、已确认的产品参数、软件要求、验证要求和未定门槛。每项实测状态与证据以[R01–R22验收矩阵](servo_requirements_acceptance_matrix.md)及对应验证记录为准。

**版本：** 1.3（2026-11-21）

## 1. 规格使用规则

1. 本文件是开发设计要求的入口和稳定基线；R01–R22矩阵是逐项验证状态、证据、失败原因和后续验证方法的唯一状态清单。
2. 明确标为“已确认”的数值是规格或用户确认的设计约束；标为“历史参考”的数据不自动成为当前验收限值；“待定/待验证”不能被描述为通过。
3. 板上/固件的当前状态随测试变化，应更新矩阵和相应Rxx记录；稳定的设计要求及其来源变化时更新本文件。修改源码、构建配置或方法时，按项目记录规则及时追加目的、文件、结果、哈希（适用时）、板况和未解决项。
4. 原始规格书、原理图和用户已确认参数优先于旧候选代码中的默认值。发现冲突时，记录冲突和处置，不得把旧固件行为误当成产品要求。

## 2. 产品与系统定义

本项目控制一套有刷直流电机、BTL H桥、减速机构和电位器位置反馈组成的舵机。MCU读取PWM位置命令和电位器反馈，生成方向及PWM驱动，使轴到达目标位置并稳定保持。软件还需测量响应、适应对象差异、保存合格模型，并在输入、反馈、供电或调度异常时安全降级。

当前只推进TSSOP20板。它是开发/验证平台，不应与最终SOP8产品板的IO映射混用。验证按“源码/离板检查→同版构建→受控板测→需求验收”递进；编译、下载成功或单项模拟均不等于整机通过。

### LCDM已确认显示链路（下次调试优先复用）

- TSSOP20仿真板的已验证组合：USART1硬件TX映射PA7/AF8，230400 baud；LCD命令以`page/cls/fill/xstr`直接绘制P50整页。不要把已显示的直绘代码改成仅更新缓存/控件值，也不要擅自换成GPIO软串口或改波特率。
- 复用屏端既有页面做运行时直绘时，必须先`vis 255,0`隐藏旧控件、`tsw 255,0`屏蔽旧控件触摸，再打开`sendxy=1`；绘制提交后立即再次`ref_stop`。仅停MCU刷新或仅停屏端周期刷新都会留下触摸重绘覆盖风险。R54已由用户实板确认触摸后不花屏；所有后续LCDM修改前必须核对该规则。
- R41显示页将H桥四路PWM duty分两行标为`PA6/PB0`与`PA1/PA2`，单位permille；正向占空映射到PA6/PB0，反向映射到PA1/PA2，coast四路为0。该字段是固件HBridge状态映射，不是引脚电压采样值。
- R55及后续FWD/REV点动诊断页将实时raw ADC按当前左右映射反算为等效脉宽显示在P行，A行仍是raw ADC；这只是位置对应脉宽的显示，不是MCU输出PWM脉冲宽度。R56的100‰命令对应示波器实测1ms周期/100µs高电平；R57升至150‰后用户报告有些角度可转、有些推不动。R60起由HBridge 20µs ISR硬截止点动；R64/R65局部测试显示响应随位置变化且coast滑行明显。R66为185‰、8-count触发门槛、60ms硬截止：局部REV由位置门槛先停，最终偏移约−14 ADC；随后FWD由时间门槛先停，最终偏移+10 ADC。板上当前R66空闲、coast；R01未通过。详见R01验证记录，端点测试仍留到最后。
- 2026-11-21用户目视确认R34恢复显示；固件为纯显示测试且H桥强制coast。R34候选BIN SHA256=`d10b9386385ccda7e636c39ebe4a7750c6fe09eb37f7146b3b86033583d012cf`。写后SWD读回未完成，故此处只确认显示方式，不代表镜像全片读回验收。过程见[R01验证记录](r01_validation_20261110.md)。

## 3. 已确认的产品与运行参数

### 3.1 输入、位置与行程

| 参数 | 开发设计基准 | 属性/说明 |
|---|---:|---|
| PWM有效规格范围 | 500–2500µs | 产品参考规格；不是建议反复打到机构端点 |
| 中立命令 | 1500µs | 中立独立保留，可按机构中心偏移校准 |
| 标称工作角行程 | 1000–2000µs约90°–100° | 原始规格书给出的标称关系，实体角度待同版校准 |
| 规格全范围角行程 | 500–2500µs约180°（CYS-S3047机械限位180°±10°；S0100参数表约210°） | 来源资料的具体机构角度不同；电位器转角约200–270°/标称220°。机械端点按实际机构决定，不作为日常运行目标 |
| 日常命令范围 | 600–2400µs | 用户确认的正常运行余量；不要求触碰机械端点 |
| 微小响应目标 | 1–3µs | 规格灵敏度目标；需在安全条件下验证，不把命令分辨率等同于机械响应 |
| S0100死区 | 3–8µs | S0100调试参数表的连续转动后反向单步死区要求 |
| CYS-S3047死区 | 6–12µs | CYS-S3047独立规格书数据；保留型号来源，不覆盖S0100指标 |
| 中立回归精度 | ≤0.5° | S0100参数要求；多次转动回到1500µs原位后角度误差不超过0.5° |
| 标称行程角度误差 | ≤2° | 1000–2000µs标称90°–100°行程内，相对角度误差要求 |
| 运动连续性 | 不可跳动；重复1000→2000→1500µs后应回到原位 | 原始研发要求；需按目标板同版数据评估 |
| PWM方向 | 脉宽增大为顺时针、减小为逆时针 | 已有历史方向定论；不再重复做无目的方向确认。当前固件的映射和实物响应仍需同版验证 |
| 反馈ADC | 12bit，名义0–3.3V对应raw 0–4095；当前PA4 | 实际电气和机械可用范围由当前板测得，不能假设机械端点等于0/4095 |
| 校准点 | Lo / Md / Hi及左右行程可分别设置 | 中心允许偏移，两侧不要求对称；标定可调范围600–2400µs。RAM掉电保持行为需单独确认 |

### 3.2 电机、供电及速度

| 参数 | 开发设计基准 | 属性/说明 |
|---|---:|---|
| 项目统一电机工作电压 | **4.8–8.4V** | 用户确认合并CYS-S3047的4.8–6.0V与S0100的6.0–8.4V范围；电机电源身份不能用MCU VDD代替 |
| 旧版参考电路 | DC6V供H桥/马达；ME6209输出3.3V逻辑VDD | 见`C8051F850 SCH.pdf`；用于确认电源拓扑，硬件版本需与当前板资料对应 |
| 普通DC马达参考 | DC5–8V，约23000rpm、70mA | 普通马达资料，不覆盖S0100的5.8A/20000rpm规格，不能将两组电机参数混为一组 |
| S0100电机参数 | DC7.4–8.4V、5.8A、20000rpm±10% | 原始舵机参数表；电流、转速仍是来源型号数据；项目允许工作范围按用户确认统一为4.8–8.4V |
| CYS-S3047空载速度参考 | 5V：0.133s/60°；6V：0.115s/60° | 独立型号的原厂规格；只作该型号历史性能参考，其它电压、负载和齿轮箱下不得外推 |
| 电机PWM载波 | 330–25000Hz可调 | 原始参数表；当前实现/噪声/驱动损耗需验证 |
| 日常机械安全 | 先小幅、慢速增加/减少；若PWM继续变化而电位器电压/反馈不再变化，立即回退一点 | 用户明确的调试约束；最大/最小端点留到调试最后逐步逼近，不得大幅冲击或卡齿 |

**供电使用原则：** 项目统一工作范围为4.8–8.4V，这是用户确认将CYS-S3047的4.8–6.0V与S0100的6.0–8.4V范围合并后的开发规格。旧版参考电路标称DC6V，属于标称设计点，不是全范围上限。5V/6V空载速度等数据仍按来源型号和测试点标注，不据此推定全电压、全负载性能。模型仍按马达/齿轮箱、负载和实际供电工况建档；VREFINT只监测MCU VDD/VDDA，不测电机电源。项目电压范围已明确，不再把“供电规格未知”作为阻塞；实际供电档案是否需运行时测量，取决于模型匹配策略。

## 4. 软件与安全设计要求

1. **闭环定位：** 按命令PWM映射到可校准目标位置，读取PA4反馈并以误差控制H桥；中立、偏移、左右行程允许分别校准。
2. **时间一致性：** 速度、加速度、制动预测、轨迹和保持计时按实际tick差计算；采样中断或过期数据不能伪造速度/学习结果。
3. **对象辨识与自适应：** 依据实际施加的signed duty与位置/速度响应，按方向学习马达、桥、电源、齿轮箱和负载的等效响应；质量不合格的样本必须拒学。模型变化须限幅、限速并结合置信度。
4. **轨迹及制动：** 命令路径应限制速度、加速度和占空变化；依据同方向真实制动样本估计停车距离，样本不足时保守运行。反向制动必须随原方向速度平顺降至零，不得形成反向驱动；coast与电气制动需区分。
5. **到位与保持：** 位置误差、速度及连续稳定时间共同决定到位；HOLD锚点/保持与运动制动分开。外力轻推释放后不得出现不可控冲击或持续往返。
6. **响应与性能：** 快环目标约1kHz；运动时间、过冲、终点误差、静止抖动和稳定时间分别记录。现存资料未给齐当前产品的过冲/静态误差/抖动/稳定时限验收门槛，不能用历史波形代替同版统计。
7. **故障安全：** 输入失联、ADC无效/突跳、异常速度、堵转、供电异常及调度超时必须有定义的降级；异常时冻结学习。H桥两方向不得重叠，换向需满足驱动器所需保护时序。
8. **模型存储：** 双槽、CRC/代次及非零型号、非零profile、参数指纹、供电档案匹配；未定义的零model/profile不得保存或加载。只有经过可信稳定/静止/安全资格、节流和coast维护窗口才可保存，断电/写入失败应保留旧有效槽。
9. **客户波形参考：** 按用户2026-11-22最新指定，客户样品动作参考为`2026/1000-1500.logicdata`、`2026/1500-2000.logicdata`、`2026/2000-1000.logicdata`，解读时须先确认通道/探头映射和PWM逻辑，再与我方实际双路引脚波形对齐。此前`PY32F002_SIGNAL_CAPTURE/CUSTOMER.logicdata`作为历史客户参考保留。VSG软件估算值不等于物理引脚波形；其他`2026/PA7串口*.logicdata`不得混作马达参考。
10. **版本和发布：** 每个候选固定目标、源码/SDK/flags、BIN及哈希；下载前读板识别并整片备份，under-reset写入后全片读回、核对应用和保留区。构建、下载或单次动作成功都不单独代表产品验收。

## 6. 暂未定为客户承诺的门槛

以下内容目前仍待量化或验证，不能直接作为客户承诺：最大过冲、进入稳定区的最长时间、静止峰峰抖动、堵转触发/恢复界限、不同电压和负载下的速度与扭矩、FLASH自动保存最小间隔、H桥物理死区/波形阈值。中立回归≤0.5°和1000–2000µs角度误差≤2°已有要求，但当前版本尚无同版测量证明达标。需求矩阵中的历史版本值不得直接复制成当前版本承诺。
