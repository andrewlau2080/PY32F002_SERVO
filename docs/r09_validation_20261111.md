# R09 制动距离预测核对

更新：2026-11-13  
对象：工作区 V10.6 LCDM 控制路径；板上仍为 V10.5  
结论：**方向性学习减速度已接入预刹距离判定，离板计算和构建通过；R09 整体仍未通过，等待实板速度/停车距离对照。**

## 本次代码推进

- `Servo_Adaptive_Update()` 按运动方向累计 brake acceleration 与样本数；现新增可读的方向样本计数。
- `inc/lcdm_brake_predictor.h` 用 Q4 ADC/ms 速度和 Q8 ADC/ms² 减速度计算 Q4 停车距离：`ceil(v² × 8 / a_q8)`，另加 4ms 反馈延迟距离。少于 8 个同方向样本或减速度为 0 时不启用预测。
- LCDM 普通闭环用当前速度方向选择 forward/reverse 模型；预测停车距离达到剩余位置误差时进入现有预刹分支。原有速度/误差预刹门限仍并行保留，预测只可能提前触发，不会取消已有预刹条件。客户固定 profile 继续保留既定波形，不走该预测分支。

## 未通过原因与限制

- R03 速度估算虽然已经按 HAL tick 差更新，真实速度单位/时序和方向符号尚未实板确认；学习的 brake acceleration 也没有不同速度和负载下的物理对照。
- 当前样本门槛只限制方向样本数，不能证明模型适用于不同机构、供电和负载；模型身份/工况门控尚未补齐（R21）。
- 当前启动加载的持久化 brake acceleration 不携带方向独立的样本计数门槛，因此本预测器不会仅凭旧 Flash 值启用；必须在本次运行中积累 8 个对应方向样本。
- 本版固件未下载，未采集预测停车距离、预刹起点和最终停点；客户固定 profile 不使用这个预测器。

## 需要用户协助

- 目前没有需要用户立即操作的事项。方向映射沿用用户此前定论；R09实测待当前候选的同步采集流程就绪，用于核对预测制动和实际停点。
- 后续实测需 DAPLink 接 Ubuntu、仿真板连接可观察舵机/电位器；先在安全中位确认方向，再用内部 PWM 覆盖正反向及不同速度，记录时间戳、位置/速度、剩余误差、方向 brake acceleration/样本数、预刹阶段和停车位置。
- 标定跨供电/负载时需记录实际供电和机构工况；用户协助提供的必要信息是仿真板当前接线/可观察转臂条件，以及允许的中位小步范围。端点留到最后并逐步靠近。
