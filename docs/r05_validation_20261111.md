## 实际覆盖范围与缺口

- 当前估计量是正反向速度增益、滑行衰减和制动减速度的局部 EMA；不是对马达、驱动、电源、齿轮箱和负载的完整动态辨识，也没有残差/协方差、堵转和电源异常的完整拒学逻辑。
- 输入 `HBridge_GetDuty()` 返回软件侧有符号 duty 状态；它不是独立捕获的两路 MOSFET 门极/PWM 波形，也不测电机电流、电压或转矩。
- 通用路径的有效标志组合 `input_valid && startup_done && velocity_valid`；LCDM 路径组合 `fresh && lcdm_servo_adc_is_valid(raw_adc)`，主要确认输入新鲜及 ADC 不在近电源轨。两者都没有完整的 ADC 突跳、堵转和供电异常质量判定。LCDM observer 现按真实 tick 差归一且离板19/19，但没有实板运动校验，因此其现场样本仍不能证明真实速度和方向符号。
- 当前主机测试只证明注入数据时的模块门槛和公式；没有从实际电位器、H 桥两路 PWM 和马达获得同步样本。
