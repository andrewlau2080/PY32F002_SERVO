## 源码核对

此前每周期重置轨迹位置/速度的问题已修复。`inc/lcdm_trajectory.h` 使用 HAL tick 差推进 Q4 位置和速度；速度受参数上限约束，速度变化受加速度参数和经过时间约束，超过 4ms 的调度间隔会从实际反馈重建基准。普通闭环速度环读取轨迹速度，位置修正读取轨迹位置误差。客户固定 profile 分支仍保留既有固定波形策略，不经过该普通轨迹规划器。

普通分支仍有最大 duty 限制、接近目标 duty 软上限、输出 slew 和反向 coast dead-time；slew 已按真实经过时间归一。客户固定 profile 分支仍以固定时长和 duty 执行 drive/brake/tail/coast，绕过普通分支的 duty slew。
